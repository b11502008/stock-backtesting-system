# 📊 Multi-Strategy Stock Backtesting System

A **multi-strategy stock backtesting system GUI tool** built with Python and PySide6. It supports simulating and evaluating stock trading strategies based on MA (Moving Average), KD indicators, and Bollinger Bands, with visualization features for comparing strategy performance against the Taiwan Weighted Index ETF (0050).

**I served as the frontend–backend integration developer, bridging the GUI with the core backtesting logic and implementing the data flow, strategy configuration, and performance visualization.**

---

## 🚀 Features

* ✅ Supports multiple technical indicator strategies (MA / KD / Bollinger Bands)
* ✅ Visualizes strategy return curves
* ✅ Supports backtesting and comparing multiple strategies simultaneously
* ✅ Displays key performance metrics (Win Rate, Total P&L, Maximum Drawdown, Annualized Return)
* ✅ Includes an option to compare performance against the market benchmark (0050)

## 🖥️ How to Run

### 1. Prepare Stock Data

Place individual stock CSV files in the `data/` directory. Each CSV file must contain the following columns:

* `Date`
* `Close`

The `0050.csv` file (Taiwan's major ETF benchmark) should also be placed in the `data/` directory and will be used as the benchmark return curve.

### 2. Launch the GUI

Run the following command:

```bash
python main.py
```

### 3. Usage

* Click `Add Strategy` → Select a strategy type and configure its parameters
* Add multiple strategies as needed
* Click `Start Backtest` to run the simulations
* Use the checkboxes below the chart to select which strategies and benchmark performance to display
* The performance summary for each individual strategy is displayed on the left panel

---

## 🧠 Strategy Details

### MA Strategy

* `ma_short`: Short-term moving average period
* `ma_long`: Long-term moving average period

### KD Strategy

* `kd_window`: Window size used to calculate the KD indicator
* `upper_bound`: Overbought threshold
* `lower_bound`: Oversold threshold

### Bollinger Bands Strategy

* `boll_window`: Moving average period
* `std_multiplier`: Standard deviation multiplier

## 📝 Output

The performance data generated by each strategy is saved in the `asset_csv/` directory:

* `Strategy1_Asset_Record.csv`
* `benchmark_asset.csv` (0050)

---

## ⚠️ Notes

* All strategies are **fully backtested before the results are displayed**. The calculation process is not affected by whether a strategy is selected or deselected in the chart.
* The GUI is built with PySide6. **Do not mix PyQt5 UI modules with PySide6.**
* Incorrect data formats may cause files to be skipped or errors to occur. Please make sure every stock CSV contains both `Date` and `Close` columns.

## 📂 Additional Modules

These modules are not required to understand the basic usage of the system:

* `backtester/`: Core strategy execution and backtesting logic
* `strategies/`: Implementations of individual trading strategies
* `gui/`: GUI controllers and UI components
* `compare_strategy.py`: Used for merging strategy performance data and calculating return statistics
* `utils/`: Utilities for manually updating stock trading data and adding newly listed stocks to the backtesting target list
